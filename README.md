# RunRuun GPX Editor

> **실제 도로 중심선(Centerline) 맵 매칭 및 인터랙티브 코스 편집을 지원하는 독립형 정적 GPX 웹 편집기**

`RunRuun GPX Editor`는 마라톤, 로드 레이스, 트레일러닝 코스의 GPX 트랙 데이터를 브라우저에서 직접 시각화하고, GPS 오차로 인한 튐이나 도로 이탈 구간을 실제 OpenStreetMap 도로 중심선에 정밀하게 스냅(Snap)하거나 편집할 수 있는 도구입니다.

외부 복잡한 빌드 도구나 백엔드 서버 없이 브라우저 단독으로 실행 가능한 독립형 정적 웹 애플리케이션으로 설계되었습니다.

---

## 🚀 빠른 시작 (설치 및 실행 방법)

본 프로젝트는 순수 HTML5, CSS3, JavaScript로 제작되어 별도의 의존성 설치 과정(`npm install`)이 필요 없습니다.

### 1. 로컬 파일 직접 열기
- 저장소를 클론한 후 브라우저(Chrome, Safari, Edge 등)에서 `index.html` 파일을 더블 클릭하여 바로 실행할 수 있습니다.

### 2. 로컬 웹 서버로 실행 (권장)
OSRM API 비동기 통신 및 타일 로딩을 가장 원활하게 수행하기 위해 간단한 로컬 정적 서버 실행을 권장합니다.

```bash
# Python 내장 서버 이용 시
python3 -m http.server 8080

# 또는 Node.js npx serve 이용 시
npx serve .
```
브라우저에서 `http://localhost:8080`에 접속합니다.

## ✨ 핵심 기능

1. **실제 지도 기반 고해상도 시각화**
   - **OpenStreetMap & CartoDB** 기반의 실제 도로망 지도 타일 제공
   - 다크(Dark), 라이트(Positron), 표준(OSM), 등고선 지형(OpenTopoMap) 테마 실시간 전환
   - 지도 확대, 축소, 팬 이동 및 전체 코스 뷰 맞춤(Fit Bounds)
   - **원본 경로(보라색 점선)**와 **수정 경로(에메랄드 실선)**를 동시에 표시하여 보정 전후 즉각 비교

2. **직관적인 포인트 정밀 편집**
   - 지도 상의 임의의 경로 포인트를 클릭하여 즉시 선택
   - 선택된 포인트를 마우스로 드래그하여 원하는 위치로 즉시 좌표 이동
   - 위도(Latitude), 경도(Longitude), 고도(Elevation) 수치 직접 입력 및 수정
   - 불필요한 단일 포인트 삭제 (`Delete` 키 지원)

3. **구간 선택 및 일괄 삭제 (직선 연결)**
   - 시작점(A)과 종료점(B)을 지정하여 사이의 중간 포인트들을 일괄 삭제
   - 복잡하게 꼬인 코너나 우회로를 손쉽게 단순화

4. **실제 도로 중심선 맞춤 (OSRM Match API)**
   - 선택 구간 또는 전체 코스를 OpenStreetMap 실제 도로망 중심선에 정밀 밀착
   - 차도(driving), 자전거/지선(cycling), 보행로(walking) 등 프로파일 지원
   - 대규모 좌표 데이터 처리를 위한 지능형 청크(Chunk) 분할 전송
   - 매칭된 도로 좌표에 원본 지형의 고도 데이터를 누적 거리 비율 기준으로 부드럽게 선형 보간(Interpolation)

5. **스마트 구간 재연결 (OSRM Route API)**
   - 잘못 우회한 구간이나 단절된 두 지점(A, B)을 선택
   - 실제 도로망을 경유하는 최적 우회 경로를 실시간 탐색
   - 적용 전 하늘색 점선으로 경로 미리보기(Preview) 제공 및 사용자 승인 시에만 병합

6. **인터랙티브 고도 프로파일 & 실시간 통계 HUD**
   - 무의존성 Canvas 고도 차트 내장
   - 차트 호버 시 지도 상에 해당 위치가 펄싱 인디케이터로 실시간 연동
   - 총 거리(km), 누적 상승고도(Elevation Gain, m), 누적 하강고도, 최고/최저 고도 실시간 집계
   - 원본 대비 거리 및 상승고도 변동률(Delta, %) 실시간 비교

7. **완벽한 실행 취소/다시 실행 (Undo / Redo)**
   - 최대 50단계 히스토리 스택 제공 (`Ctrl+Z`, `Ctrl+Y` 지원)
   - 실수로 인한 데이터 손실 방지

8. **표준 GPX 1.1 데이터 내보내기**
   - 원본 코스 이름 및 메타데이터 구조를 최대한 보존하며 표준 규격의 GPX 파일 생성

## ⚠️ 기술적 한계 및 유의사항 (Limitations)

- **산길 및 비포장 트레일 처리 주의**:
  - OSRM 도로 매칭 엔진은 차량/자전거/보행 도로망 데이터를 기반으로 작동합니다.
  - 도로망이 없는 산길, 숲길, 능선 트레일 구간을 '전체 도로 매칭'할 경우 인근 일반 도로로 강제 우회될 수 있으므로, 해당 구간은 일반 '포인트 편집 모드'를 사용하시기 바랍니다.
- **포인트 삭제 시 연결 방식**:
  - 구간 내 중간 포인트를 삭제할 경우 두 끝점 사이는 기본적으로 직선으로 연결됩니다. 도로 곡선을 유지해야 하는 경우 '구간 재연결(OSRM Route)' 기능을 활용해 도로망 경로로 다시 채워 넣을 수 있습니다.
- **GPX 메타데이터 보존 범위**:
  - 표준 트랙 요소(`trk`, `trkseg`, `trkpt`, `ele`, `time`, `name`)는 정밀하게 보존 및 갱신되나, 특정 GPS 기기 전용 독점 확장 태그(Vendor-specific Extensions: 심박수, 케이던스, 파워 등)는 도로 매칭 시 좌표 노드가 재구성되면서 유실될 수 있습니다.
- **외부 API 서비스 이용 규정**:
  - 도로 매칭 및 경로 재연결 기능은 공개 OSRM(Project-OSRM) 데모 서버를 활용합니다. 연속적인 대용량 요청 시 네트워크 지연이나 서비스 제한이 발생할 수 있으므로, 상용 서비스 환경에서는 자체 호스팅 OSRM 인스턴스 구축을 권장합니다.
